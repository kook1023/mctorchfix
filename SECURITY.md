# Security Policy

## Supported Versions

TorchlightFix is a small personal project. Security fixes will be provided on a best-effort basis.

| Version | Supported |
| ------- | --------- |
| Latest release | ✅ |
| Older releases | ❌ |

## Reporting a Vulnerability

If you discover a potential security vulnerability in TorchlightFix, please report it privately through GitHub's **Report a vulnerability** feature, if available.
Please include a description of the issue, the affected version, and steps to reproduce it.

I will review reports as time allows. There is no guaranteed response time or promise that every report will result in a fix.

Please avoid publicly disclosing exploitable vulnerabilities before giving me a reasonable opportunity to investigate them.
